# 🧠 Interview Simulator

An interactive, AI-powered platform designed to simulate real technical interviews — helping candidates practice coding, behavioral, and situational rounds in a realistic environment.

---

## 🚀 Overview

**Interview Simulator** aims to bridge the gap between *preparation* and *real experience*.  
It replicates real interview conditions using:
- **AI-based question generation**
- **Real-time evaluation**
- **Personalized feedback and scoring**
- **Voice-based and text-based interaction modes**

The project is built using **Python**, **Flask**, **PostgreSQL**, and **Supabase**, with a clean, responsive web interface.

---

## 🧩 Features

✅ **AI Question Generator** – dynamically generates coding, aptitude, and HR questions.  
✅ **Live Coding Simulation** – write and execute code directly in-browser.  
✅ **Real-time Feedback** – evaluate your performance instantly.  
✅ **Mock HR Round** – answer behavioral questions with voice/text input.  
✅ **Progress Tracker** – visualize improvement over multiple mock sessions.  
✅ **Cloud Sync** – all data stored safely using Supabase + PostgreSQL.
